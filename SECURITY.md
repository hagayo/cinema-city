# Security Policy

## Supported Versions
We actively monitor and patch the current major version of this project.

| Version | Supported          |
| ------- | ------------------ |
| 1.0.x   | :white_check_mark: |
| < 1.0   | :x:                |

## Reporting a Vulnerability
Do not open a public GitHub issue for security vulnerabilities. Instead, please report security bugs by creating a [GitHub Security Advisory](https://github.com).

We will acknowledge your report within 48 hours and provide a fix as soon as possible.
